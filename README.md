# PULSO

Sistema web académico desarrollado con HTML, CSS, JavaScript, PHP y MySQL.

## Inicio rápido con XAMPP

1. Iniciar Apache y MySQL.
2. Importar `pulso_base_de_datos.sql`.
3. Confirmar que `conexion.php` utilice la base `pulso_entrega`.
4. Colocar el proyecto en `C:\xampp\htdocs\pulso-entrega` o crear un vínculo hacia esa ruta.
5. Abrir `http://localhost/pulso-entrega/`.

El procedimiento completo, las pruebas realizadas y la solución de errores frecuentes se encuentran en [PASOS_PARA_PROBAR_CON_XAMPP_Y_MYSQL.md](PASOS_PARA_PROBAR_CON_XAMPP_Y_MYSQL.md).
